# Assignment 4：Bézier 曲线

## 运行

在窗口中依次左键选择四个控制点，程序分别使用三次 Bernstein 多项式直接公式和 de Casteljau 递归算法绘制曲线，并将 `my_bezier_curve.png` 保存到当前工作目录。

选点过程中按 `Esc` 退出；绘制完成后按任意键退出。

## 曲线重叠验证

- 红色：`NaiveBezier()` 使用直接公式绘制的曲线。
- 绿色：`Bezier()` 调用 `RecursiveBezier()` 绘制的曲线。
- 黄色：两种方法覆盖了同一个像素，可用于直观检查曲线是否重叠。

OpenCV 使用 BGR 通道顺序。两条曲线分别将红、绿通道设置为 `255`，重叠处为 `(0, 255, 255)`，因此显示为黄色；白色控制点标记覆盖的区域可能仍显示为白色。

两种方法使用相同的参数采样步长和像素取整方式。曲线大部分呈黄色，说明两者的绘制结果基本一致；由于浮点计算顺序不同，少量采样点可能落在相邻像素，出现红色或绿色边缘。这种显示用于辅助检查，不能替代对曲线点坐标误差的数值比较。
