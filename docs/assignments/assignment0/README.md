# Assignment 0：环境准备

验证 Eigen 和 OpenCV 的环境

## Eigen 使用注意事项

- Eigen 矩阵默认采用列主序（Column-major），注意区分向量方向与矩阵存储顺序。
- 矩阵乘法 `A * B` 与逐元素乘法 `A.cwiseProduct(B)` 不同，运算前需确认维度匹配。
- 创建矩阵或向量后，若需要零值，应显式使用 `setZero()` 初始化。
- 使用 `auto` 保存运算表达式时，注意表达式求值时机及对象生命周期。

## OpenCV 使用注意事项

- 图像坐标原点通常在左上角，x 向右、y 向下。
- `cv::Mat` 访问像素时使用 `image.at<T>(y, x)`，而 `cv::Point` 使用 `(x, y)`。
- OpenCV 彩色图像默认通常采用 BGR 通道顺序，而不是 RGB。
- `cv::Mat` 复制或提取 ROI 时可能共享底层数据，需要独立副本时使用 `clone()`。
- 注意图像的数据类型和通道数，例如 `CV_8UC1` 表示单通道 8 位图像，`CV_8UC3` 表示 3 通道 8 位图像。
- 图像行内存可能包含额外步长，不要默认所有像素数据都连续存储。
